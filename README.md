# Semaforge
The Semaforge Programming Language
## Goals
* Runs ontop of LLVM and MLIR to target CPUs and GPUs alike
* Large Std Lib
* Compilation times as fast as Go
* As memory safe as Rust
* As much low level control and speed as C
* Powerful Macro system like Lisp/Julia(Syntax/DSL creation/editing that won't break if the AST needs updating)
* Build system as powerful, robust, and easy to use as Zig(fuck you CMake)
* Lots of builtins that you can take or leave (HTTP Server, GUI Library(later), package manager, LSP)
* My favorite features from other languages (typeclasses, generics, FFI for C and ASM)
* Interoperability with C so as to seamlessly integrate with it :$ hopefully, probably meaning it will have to follow the C standard as a baseline...hmm
    * or maybe mixing their binaries together like zig..eh
